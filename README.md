# Desktop Island

Остров в стиле Dynamic Island сверху экрана для Windows и Linux. В свёрнутом виде показывает время, музыку, таймер, звонок или загрузку, по нажатию раскрывается в панель с карточками.

## Возможности

- **Уведомления** всех программ прямо в острове, сгруппированные по приложениям. Системные баннеры Windows не мешают.
- **Телефон** через бесплатное приложение [KDE Connect](https://kdeconnect.kde.org): уведомления и ответы на них (закрытые на компьютере пропадают и с телефона), SMS-переписка, музыка с телефона, звонки, заряд, общий буфер обмена, файлы (можно перетащить на карточку «Телефон»), «Найти телефон». Телефон работает как тачпад, клавиатура и пульт для презентаций, а кнопками-командами блокирует ПК, усыпляет его, выключает звук и т. д.
- **Музыка**: обложка, управление, текст песни строкой или на весь остров.
- **Звонки, микрофон и камера**: длительность звонка, кнопка микрофона, индикаторы.
- **Заметки и напоминания** текстом и голосом: «позвонить маме в 18:30». Голос превращается в текст без интернета.
- **Календарь** по ICS-ссылке, **Помодоро**, таймеры с будильником и секундомер.
- **Загрузки** из браузера и **Steam**: название, прогресс, скорость и сколько осталось.
- **Полка** для файлов: перетащите файл на остров. Снимок области экрана, текст с картинки и перевод.
- **Центр управления**: Wi-Fi, Bluetooth, режим полёта, энергосбережение, VPN (Happ, INCY), громкость каждой программы, наушники, яркость.
- **Подсказки**: громкость (вместо плашки Windows) и яркость, смена раскладки и Caps Lock, подключение VPN, режим полёта — коротко в острове.
- **Приложения**: поиск и запуск, в том числе от имени администратора.
- **Внешний вид**: стили острова (жидкое стекло, неон, аура, графит), темы и свой редактор тем — все цвета вручную для тёмной и светлой палитры, цвет и свечение острова, скругления, градиентный фон, прозрачные карточки, подбор цветов из картинки и предпросмотр на острове; темами можно делиться кодом или файлом; 10 шрифтов и свои TTF/OTF, звуки уведомлений и таймера, обои и прозрачность окна настроек, русский и английский.

## Как пользоваться

- Нажмите на остров, чтобы раскрыть, и мимо него, чтобы свернуть.
- Колесо мыши над раскрытым островом листает карточки.
- Остров можно перетащить мышью. Правая кнопка открывает настройки.
- В приложениях Ctrl+Shift+Enter или значок щита запускает программу от имени администратора.

| Действие | Сочетание |
|---|---|
| Показать или скрыть остров | Ctrl+Alt+I |
| Раскрыть панель | Ctrl+Alt+E |
| Центр управления | Ctrl+Alt+Q |
| Пауза музыки | Ctrl+Alt+P |
| Не беспокоить | Ctrl+Alt+D |

Сочетания меняются в «Настройки → Подключения → Горячие клавиши».

## Если что-то не так

- **«Система Windows защитила ваш компьютер»**: нажмите «Подробнее» → «Выполнить в любом случае».
- **Telegram присылает только «Новое сообщение»**: в Telegram «Настройки → Уведомления и звуки» включите «Использовать системные уведомления».
- **Не проверяются обновления** (ошибка сертификата или нет связи с GitHub): приложение само пробует обходные пути, а если сеть блокирует GitHub полностью — скачайте установщик по ссылке выше.
- **AppImage не запускается**: `sudo apt install libfuse2t64` (на старых Ubuntu `libfuse2`).
- **Wayland**: назначьте сочетание клавиш на команду `desktop-island --toggle`.
- Остальное — в [Issues](https://github.com/skree3/Desktop-dynamic-island/issues), приложите вывод `desktop-island --selftest`.

## Приватность

Данные хранятся только на компьютере. В интернет приложение обращается за обновлениями, текстами песен (lrclib.net) и календарём, а для перевода и загрузки модели распознавания речи — только по вашей кнопке. Всё это отключается в настройках.

## Разработка

Rust (Tauri 2) и React. `npm install`, затем `npm run tauri dev`. Релиз собирается на GitHub по тегу `vX.Y.Z`, список изменений берётся из `.github/release-notes.md`.
