# Desktop Island

Чёрная «чёлка» сверху экрана, как Dynamic Island на iPhone, только для Windows и Linux. В свёрнутом виде показывает время, играющий трек или таймер. Нажмите на неё, и откроется панель: музыка, Wi-Fi и Bluetooth, громкость, заметки, полка для файлов, уведомления.

В версиях .deb и .rpm эта кнопка открывает страницу загрузки, потому что для установки нужны права администратора.

## Что умеет

- **Музыка.** Spotify, Яндекс Музыка, YouTube в браузере, VLC на Linux и вообще всё, что показывает системный медиаплеер. Обложка, прогресс, пауза, переключение треков.
- **Уведомления.** Telegram, Discord, почта и другие программы приходят прямо в остров. Ничего настраивать не нужно.
- **Центр управления.** Wi-Fi, Bluetooth с названием подключённого устройства, громкость, яркость, прозрачность панели, выключение и перезагрузка.
- **Таймеры** и секундомер. Работают, даже если панель свёрнута.
- **Заметки.** Пишете строчку, нажимаете Enter, она сохраняется.
- **Полка.** Перетащите файл на остров, и он будет лежать там, пока не понадобится. Можно открыть, показать в папке или скопировать, чтобы вставить в чат.
- **Зарядка.** При подключении зарядки остров на пару секунд показывает уровень заряда. При 20% и 10% предупреждает.
- **Игровой режим.** Во время игр остров прячется и не мешает. Видео на весь экран его не скрывает.

Ещё можно включить системный монитор, буфер обмена (тот же журнал, что по Win+V), поиск программ и мини-окна ChatGPT, Claude, DeepSeek и Gemini. По умолчанию они выключены, чтобы панель не была перегружена: «Настройки → Карточки → В панели».

## Как пользоваться

- **Нажмите** на остров, чтобы его открыть. Нажмите в любом другом месте экрана, чтобы закрыть.
- **Колесо мыши** над открытой панелью листает разделы. Ещё можно нажимать на точки сверху.
- **Перетащите** остров мышью, чтобы поставить его в другое место. Если отпустить его у верхнего края, он снова прилипнет к краю.
- **Значок прицела** в открытой панели возвращает остров наверх по центру. То же самое есть в меню значка в трее.
- **Правая кнопка** по острову открывает настройки.
- **Значок в трее**: показать или скрыть панель, скрыть на 15 минут или час, «Не беспокоить», выход.

Горячие клавиши (меняются в настройках):

| Действие | Сочетание |
|---|---|
| Показать или скрыть остров | Ctrl+Alt+I |
| Открыть или закрыть панель | Ctrl+Alt+E |
| Центр управления | Ctrl+Alt+Q |
| Пауза или воспроизведение | Ctrl+Alt+P |
| Следующий и предыдущий трек | Ctrl+Alt+→ и Ctrl+Alt+← |
| Не беспокоить | Ctrl+Alt+D |

## Плагины

Вместе с приложением идут три плагина. Включаются в «Настройки → Плагины».

- **Помодоро.** 25 минут работы, 5 минут отдыха, оставшееся время видно прямо в свёрнутом острове.
- **Привычки.** Отмечаете за день, приложение считает серии.
- **System Pulse.** Загрузка процессора и памяти.

Плагины работают в изолированном окружении: без доступа к файлам и интернету. Каждое разрешение вы подтверждаете сами при включении. Как написать свой плагин, рассказано в [docs/PLUGIN_API.md](docs/PLUGIN_API.md).

## Если что-то не так

**Windows пишет «Система Windows защитила ваш компьютер».** У установщика нет платной цифровой подписи. Нажмите «Подробнее», потом «Выполнить в любом случае».

**Не приходят уведомления из Telegram.** В Telegram Desktop откройте «Настройки → Уведомления» и включите системные уведомления. Остальные программы обычно присылают их сразу. Если какое-то приложение не нужно, выключите его в «Настройки → Уведомления → Приложения».

**Не меняется яркость внешнего монитора.** Включите DDC/CI в меню самого монитора. Если пункта нет, монитор не поддерживает управление с компьютера.

**AppImage не запускается на Ubuntu.** Установите `libfuse2`: `sudo apt install libfuse2`.

**Wayland на Linux.** Глобальные горячие клавиши в Wayland работать не могут, так устроена система. Назначьте сочетание в настройках рабочего стола на команду `desktop-island --toggle`. Есть и другие команды: `--quick`, `--dnd`, `--play-pause`, `--quit`.

**Что-то сломалось.** Опишите проблему в [Issues](https://github.com/skree3/Desktop-dynamic-island/issues). Очень поможет вывод команды `desktop-island --selftest`: она проверяет, какие функции работают на вашей системе.

## Как это устроено

Приложение написано на Rust (фреймворк Tauri), интерфейс на React. Оно лёгкое: в простое занимает около 115 МБ памяти вместе со встроенным браузерным движком, а установщик для Windows весит около 3 МБ.

Всё хранится у вас на компьютере. На Windows это папка `%APPDATA%\app.desktopisland`, на Linux `~/.local/share/app.desktopisland`. Никакой статистики приложение не собирает и никуда не отправляет. Единственный запрос в интернет — проверка обновлений на GitHub раз в 6 часов. Её можно выключить в «Настройки → Общие».

Пароли из менеджеров паролей и похожие на пароли строки в историю буфера обмена не попадают. Выключение компьютера всегда требует подтверждения.

## Для разработчиков

Нужны Rust, Node.js 20+ и системные библиотеки Tauri. Запуск в режиме разработки: `npm install`, затем `npm run tauri dev`. Сборка под Linux одной командой: `bash scripts/build-linux.sh`, скрипт сам поставит зависимости. Новый релиз собирается на GitHub автоматически, когда в репозиторий приходит тег вида `v0.2.0`.
