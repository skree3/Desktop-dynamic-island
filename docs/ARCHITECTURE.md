# Устройство Desktop Island

Два окна на React и бэкенд на Rust (Tauri 2), общаются через IPC Tauri.

## Фронтенд (`src/`)

- **Окно острова** открыто всегда. Окно фиксированного размера, внутри пружинная анимация формы. Клики мимо острова проходят насквозь.
- **Окно настроек** создаётся по запросу и закрывается целиком.
- Карточки грузятся лениво. Плагины работают в изолированном iframe.
- Состояние хранится в Zustand: `app`, `island`, `media`, `sysmon`, `timers`.

## Бэкенд (`src-tauri/src/`)

| Папка | Что внутри |
|---|---|
| `commands/` | IPC-команды: проверка входных данных и вызов модулей |
| `core/` | Настройки, окна и мониторы, горячие клавиши, темы, профили |
| `events/` | Очередь уведомлений по приоритетам и «активности» свёрнутого острова |
| `modules/` | Музыка, уведомления, таймеры, телефон, Steam, VPN, индикаторы и т. д. |
| `platform/` | Отдельные реализации для `windows/` и `linux/` |
| `plugins/` | Установка, права и API плагинов |
| `database/` | SQLite с миграциями и восстановлением |

## Главное

- **Модули работают, только когда нужны.** `modules::reconcile()` включает и выключает фоновые задачи по настройкам, видимости острова и игровому режиму.
- **Уведомления не теряются и не накладываются.** Очередь с приоритетами, группировкой по приложению, «Не беспокоить» и игровым режимом. В свёрнутом острове показывается одна самая важная активность.
- **Опасные действия подтверждаются.** Выключение и перезагрузка требуют одноразового токена.
- **Все данные локальные.** Настройки, заметки и история хранятся в SQLite в папке программы.

## Тесты

- `cargo test --lib`: логика очереди, настроек, базы, плагинов, Steam, шрифтов и звуков.
- `npm test`: форматирование, напоминания, стили.
- `desktop-island --selftest` проверяет системные функции на реальном компьютере.
