# Что поддерживается в Windows и Linux

Если функция недоступна, приложение пишет «Недоступно» и почему. Значения никогда не подделываются.

| Функция | Windows 10/11 | Linux |
|---|---|---|
| Музыка | Любой плеер с системной медиасессией (SMTC) | Любой плеер с MPRIS |
| Уведомления программ | Да, в острове вместо системных баннеров | Да (GNOME, KDE и другие через D-Bus) |
| Телефон | KDE Connect | KDE Connect |
| Громкость и устройство вывода | Да, плюс громкость каждой программы | Да (PulseAudio / PipeWire) |
| Яркость | Встроенный экран и внешние мониторы (DDC/CI) | Встроенный экран |
| Wi-Fi, Bluetooth | Вкл./выкл., сеть, устройства | Вкл./выкл. через NetworkManager и BlueZ |
| Режим полёта | Вкл./выкл. | Вкл./выкл. через rfkill |
| Энергосбережение | Включается кнопкой при работе от батареи; от сети — в параметрах Windows | Да (power-profiles-daemon) |
| VPN Happ | Подключение и отключение одной кнопкой | Да, если установлен Happ |
| VPN INCY | Показ состояния, кнопка открывает программу | То же |
| Раскладка и Caps Lock | Подсказка в острове | Caps Lock везде, раскладка в GNOME |
| Загрузки Steam | Да | Да (в том числе Flatpak-версия Steam) |
| Запуск от имени администратора | Да, с запросом UAC (не для приложений из Store) | Да, через pkexec |
| Горячие клавиши | Да | X11. В Wayland назначьте сочетание на `desktop-island --toggle` |

Программы, которых нет в списке, находятся поиском автоматически. Свои программы и сайты добавляются в «Настройки → Интеграции».
